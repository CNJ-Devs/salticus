# Salticus 隐私政策

[English](privacy.md) · [简体中文](privacy.zh-CN.md)

生效日期：2026 年 11 月 1 日。适用于 Salticus 0.4.0 浏览器扩展及配套桌面应用。
维护者为 CNJ-Devs；英文是主文档语言。

## 功能与数据

Salticus 让两个人各自在本地播放视频，通过点对点消息同步操作。
双方使用自己的账号、视频来源与网络。Salticus 不向对方传输视频或音频流，
项目不运营同步服务器、账号服务、分析服务或广告服务。

- **选择视频**：扩展检查已获许可的标签页和内嵌页面中的 HTML 视频，读取页面地址、
  来源、标题、播放器标识、时长与播放状态，以供选择和控制。选择器可能检查多个
  已获许可的标签页，但只有绑定的视频参与同步。扩展不读取浏览器的历史记录数据库。
- **播放同步**：开启 Sync 后，向选中的连接对象发送播放操作、时间、时长、视频标题、
  从来源与标题派生的不透明标识以及会话标识。同步协议不向对方发送页面地址、媒体流地址、
  Cookie、密码或会员凭据。
- **校准**：发起校准会尝试获取视频帧，或对当前可见的绑定标签页截图。截图可能包含
  周围的网页内容或个人信息。发送前由你检查图片和时间；可移除、替换图片或不带图发送。
  主动选择的图片文件只用于替换参考图。确认发送的图片仅发给选中的连接对象，不发给维护者。
- **设备与连接**：桌面应用在本地生成并保存设备证书和私钥，保存连接名称、对方身份指纹、
  连接地址及设置。分享“我的信息”会披露设备名称、公开身份指纹和连接地址。
  直连双方可以看到对方的网络地址。局域网发现会向本地网络发布设备身份和可达信息，
  可以在设置中关闭。
- **偏移**：来源配对标识、描述性标题、校准时间和偏移保存在本地，方便再次使用。

## 保存与删除

扩展使用 Chrome 本地会话存储，不使用 Chrome Sync。绑定、连接选择、运行状态与
校准草稿或请求（包括可选图片）会保存在会话中。关闭弹出窗口不会清空这些信息；
扩展或浏览器会话重置时由 Chrome 清空会话存储。

桌面应用把身份、连接、设置和偏移保存在主目录下的 `.salticus` 文件夹中，
配置迁移可能保留本地备份。私钥与本地 API 凭据留在原生应用中，不放进邀请，
也不发给对方。

可以通过应用内已有的删除入口移除连接或偏移。移除扩展会清理其存储，但不会清理桌面数据。
如需清除全部桌面数据，退出 Salticus 后移除主目录中的 `.salticus` 文件夹及其备份。
这也会删除设备身份，之后必须重新交换新身份。对方保留的数据由对方管理，无法远程删除。

## 传输与用途

同步及校准消息经过本地 Native Messaging 桥，通过证书指纹固定的 TLS 连接发给已配对设备。
双方证书必须匹配各自保存的指纹。当前没有项目中继或第三方同步服务。
你使用的 VPN、DNS、网络服务商或虚拟局域网可能依其条款处理连接信息。
本地数据受操作系统文件权限保护，没有额外的加密数据库；请保护设备与备份。

Salticus 不出售数据，不将其用于广告、画像、模型训练或数据交易。
数据仅用于同步、配对、校准与配置功能。从 Google API 获得的信息遵循
Chrome Web Store 用户数据政策，包括 Limited Use 要求。

## 权限和控制

站点权限用于读取和控制页面视频，初始声明爱一番站点权限；其他 HTTP(S) 站点和
内嵌页面来源需授权。可在 Chrome 撤销站点权限。脚本及导航权限用于查找视频和在
页面改变后解除失效绑定。当前标签页权限支持用户触发截图；Native Messaging 用于
连接已安装的桌面应用；存储用于会话状态；定时任务用于重连；通知用于提示对方发起校准。

关闭 Sync 会停止该绑定的同步控制，但不会自动断开桌面端的设备连接。
禁用连接可以停止与该设备通信；发送前可以移除图片；局域网发现可以独立关闭。

## 其他服务与联系

视频平台、Chrome 商店、Apple 分发服务及 GitHub 各自适用自己的隐私政策。
在 GitHub Issue 主动发布的信息是公开的，不要附带私钥、邀请或个人截图。
可通过[项目问题页](https://github.com/CNJ-Devs/salticus/issues)联系维护者；
私密问题请使用商店页面正式提供后的发布者联系信息。
政策的重要变化会更新生效日期并写入版本说明。
