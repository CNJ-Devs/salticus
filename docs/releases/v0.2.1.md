## Download and use

- Apple silicon: `Salticus-0.2.1-arm64.dmg`
- Intel Mac: `Salticus-0.2.1-x64.dmg`
- Requires macOS 13+ and Chrome 120+.

Open the DMG, drag Salticus into Applications, and launch it. Use Find browser extension to load the bundled Chrome extension once; it connects to the app automatically.

UI covers rooms, invitation copying/pasting, device approval, and network settings. No Node.js, npm, OpenSSL, commands, or open terminal are required. Disable the old extension before loading the matching one; identity and rooms persist.

Recognized matching videos select automatically, align initially, and propagate play/pause/seek. Only different sources need manual labels and anchors; resync is occasional recovery. There is no permanent controller.

## Preview limits and verification

- **No Apple Developer ID signing or notarization**; macOS may block Internet downloads. The extension is not in the Chrome Web Store and needs first-time manual loading.
- All 27 automated tests passed. Packaged Apple silicon startup, native bridge, and background cold start are verified; Intel hardware testing remains pending.
- Earlier live Yifan tests verified playback controls. This version's automatic alignment has integration coverage; new-extension and two-device live tests remain pending.
- Remote peers need reachable addresses or a user virtual LAN. LAN discovery does not traverse NAT. Salticus operates no room, signaling, or relay service.
- Use Wait for me / I am ready for ads. Automatic ad detection and continuous drift correction are not implemented.
