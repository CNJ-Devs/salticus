# Salticus v0.2.0 · Desktop preview

## English rebuild (2026-10-31)

This preview has been rebuilt from the English-only historical source. The release tag now points to the rewritten equivalent commit. Installers, extension/source archives, and checksums replace the original uploads; previously downloaded files have different checksums. Use the current `SHA256SUMS.txt` with the current downloads.

This remains the original group-room preview. Two-person room limits belong to the unreleased 0.3.0 development source.

## Original preview scope

Normal use now installs a macOS app with its runtime included. No Node.js, npm, OpenSSL, commands, or open terminal are required.

## Download and install

- Apple silicon: `Salticus-0.2.0-arm64.dmg`
- Intel Mac: `Salticus-0.2.0-x64.dmg`
- Requires macOS 13+ and Chrome 120+.

Open the DMG, drag Salticus into Applications, and launch it. Click Find browser extension and load that folder in Chrome once. The extension then connects through Native Messaging without a pasted local key.

Disable the old extension before loading the bundled one to avoid duplicate control. Existing identity and rooms are preserved.

## Changes

- UI for room creation, invitation copying, joining, fingerprint confirmation, and network configuration.
- Automatic main-video selection; matching videos fetch progress/state when joining and propagate play, pause, and seek.
- Manual content labels and anchors for different sources only; resync remains an occasional correction.
- Closing the window keeps the app in the menu bar. Background browser connections do not repeatedly open the window.
- Video remains local, with P2P control exchange and no project-operated room or relay service.

## Preview limits and verification

**Apple Developer ID signing and notarization are not complete**; macOS may block downloaded apps. The extension needs first-time manual loading and is not in the Chrome Web Store. Both tasks remain before general distribution.

All 27 automated tests passed. Packaged Apple silicon startup, window actions, and native bridge are verified. Intel hardware testing is pending. Earlier versions verified live Yifan controls; new automatic alignment has integration tests and awaits new-extension and two-device live checks.

Remote devices still need reachable addresses or a user virtual LAN. LAN discovery does not traverse NAT. There is no automatic ad recognition or continuous drift correction.
